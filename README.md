# 番星 · 小小宇宙

个人站点：https://fanxing724.github.io/

原生 HTML、CSS 和 JavaScript，无构建步骤或运行依赖，直接由 GitHub Pages 发布。

- 日光 / 星空双主题，默认跟随系统，可手动切换并保存偏好。
- 展示公开仓库中的 AI 陪伴、实用工具和设备探索项目，支持分类筛选。
- GitHub 数据卡片来自 [new-make](https://github.com/fanxing724/new-make)，与站点主题同步。
- 保留 C-137 实验体档案，可直接展开；无 JavaScript 时正文与项目仍可访问。
- 支持移动端、键盘导航与减少动态效果偏好。

本地预览：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

`assets/orbit-dark.webp` 复用原有角色插画；`assets/orbit-light.webp` 为基于同一角色生成的日光版本，均来自 new-make 仓库。图片不依赖外部图床。

代码主要借助 AI 完成，项目用途与描述依据各仓库公开 README 整理。
